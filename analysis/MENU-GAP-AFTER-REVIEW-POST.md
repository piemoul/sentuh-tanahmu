# Gap menu setelah rilis composer ulasan

Audit baca saja terhadap sumber aktif setelah [rilis review/post](webapp/lost-review-post-release-summary.json): **100 runtime, 176 operasi, 86 aktif: 72 baca dan 14 tulis**. Hash `app.js` dan katalog saat audit cocok dengan pin rilis itu. [Baseline Mitra](webapp/mitra-read-baseline.json) mencatat sumber, katalog dan proses Docker terkini sebelum implementasi berikutnya. Adapter aktif tetap bukan bukti penerimaan seluruh fungsi server.

Sertipikat Hilang, baca ulasan dan composer kini sudah diimplementasikan. Hapus Aktivitas, Home banner/YouTube, chooser Antrian, Cari Bidang, daftar Mitra dan fitur Koleksi juga sudah ada; snapshot [audit menu lama](MENU-COMPLETION-AUDIT-20261021.md) serta [delta lama](CURRENT-MENU-GAP-DELTA.md) tidak boleh dipakai untuk menyebutnya belum dibangun. Audit ini tidak membaca ulang akun atau mengubah sesi; tidak mengasumsikan akun kini anonim.

## Pilihan pekerjaan berikutnya

**Perbaiki baca Mitra**: decoder nullable khusus lima respons, scope GET dan query tepat, ID raw/null→String kosong, pemuatan awal dan lifecycle/retry. Pertahankan urutan sumber, filter lokal, kategori PPAT/PPATS serta Surveyor/Asisten, label/bucket jumlah akta dan browser null guards yang sudah tersedia. Validasi `kode` pada kantor serta `tempatKedudukan/status` pada PPAT meskipun native membuangnya. Jangan drop baris rusak atau mengganti `data` dengan `message`/root array. Root memilih jalur ini; kontrak native dibekukan sebelum edit runtime. Jumlah operasi aktif serta operasi tulis tidak perlu bertambah.

Tidak ada pencarian negatif APK baru, browser, request produksi, pembacaan kredensial, restart, atau mutasi akun dilakukan oleh audit ini. Satu pemanggilan ApiClient memakai transport stub memori saja. Tidak ada pengujian end-to-end/native baru. Booking akhir, Rating PPAT lengkap, seluruh menu/error/role dan geotag tetap belum selesai. Binding peta langsung Berkas tetap batas bukti yang sudah tercatat; audit ini tidak mengulang pemindaian negatif atau menebak geometri/koordinat/ID penggantinya.
