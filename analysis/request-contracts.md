# Audit statis parameter request Sentuh Tanahku 6.1.5

Pemindaian seluruh `.text` menginventarisasi **169 panggilan langsung** menuju tiga wrapper HTTP yang metodenya dibuktikan: **100 POST dan 69 GET**. Versi laporan ini meninjau **169 callsite** (100 POST, 69 GET), dengan **170 bentuk request** dan **541 path/pola field**. Beberapa bentuk memakai satu callsite; endpoint yang sama dapat memiliki beberapa callsite.

Angka cakupan tersebut berlaku untuk callsite langsung yang diketahui. Ini **bukan seluruh API server**, bukan schema wire lengkap, dan bukan bukti webapp setara dengan APK. Seluruh request dianalisis secara statis; tidak ada login, unggahan, pemanggilan backend, nilai credential/token pengguna, atau perubahan APK dalam audit ini.

File utama: [JSON dengan tipe, bukti, dan batas setiap record](request-contracts.json), [CSV seluruh field teramati](request-fields.csv), [inventaris callsite](recovered/http-callsite-audit/index.json), [provenance tool dan hash](recovered/blutter-provenance.json).

## Batas cakupan yang terukur

- 2.655.716 instruksi ARM64 dipindai. POST `0x6b9270` memakai literal POST di `0x6b935c`; POST `0x6fced8` meneruskannya melalui `0x6fd110`; GET `0x7017a4` memakai literal GET di `0x7018e8`.
- 100/100 callsite POST dan 69/69 callsite GET memiliki hasil review. 'Direview' mencakup hasil yang masih menyatakan bagian dinamis belum pulih; bukan sertifikasi semua nilai/leaf/schema.
- Requiredness server, rentang nilai, enum, kondisi izin/role, header dari interceptor, validasi, CORS/browser, dan penerimaan server belum diuji. Kontrak final wire yang tersertifikasi: **0**.
- Pemindaian awal 148 string endpoint slash hanya heuristik; endpoint survey tanpa slash, `login`, dan endpoint lain yang ditemukan dari callsite memperlihatkan batasnya. Call tidak langsung, wrapper lain, URL runtime, dan traffic plugin native tidak tercakup penuh.
- Tipe `dynamic`/unknown dibiarkan belum diketahui. Key yang selalu dibuat client tidak otomatis wajib di server. Key berpola `reviewPhoto{n}` adalah keluarga dinamis, bukan satu key literal.

## Login dan sesi

`auth/signin` membentuk map `devicePlatform`, `username`, `password` bertipe `Map<String,String>` dan memakai `application/x-www-form-urlencoded`. Platform adalah literal Android pada APK. `Authorization` memakai skema khusus `AtrBpn` dengan konfigurasi aplikasi `TRb.oYi -> Wxb.oYi -> _Xxb.oYi`. Metadata initializer dan disassembly membuktikan nilainya dibentuk deterministik dari konstanta bawaan APK, terpisah dari username/password dan token pengguna hasil login. [Bukti asal konfigurasi, tanpa nilainya](recovered/auth-config-provenance.json).

Peran nilai tersebut di server—identifier client publik, credential bersama aplikasi, atau credential dengan hak khusus—belum diketahui. Distribusi dalam APK dan header khusus saja tidak membuktikan izin penggunaan ulang, hak akses server, atau kompatibilitas browser. Audit ini tidak mengirim atau memasukkan nilainya ke webapp.

Parser respons user membaca `username`, `email`, `nomorIndukKependudukan`, `roleUser` sebagai `String?`, `userLevel` sebagai `int?`, `isParticipatoryMapper` sebagai `bool?`, dan object `token`. Parser token membaca `tokenType`, `accessToken`, `refreshToken`, `tokenVersion` sebagai `String?`, `expiredAt` sebagai `int?`. Bukti: [range-008931f8.asm.txt](recovered/request-callsites/range-008931f8.asm.txt), [range-006b1b08.asm.txt](recovered/request-callsites/range-006b1b08.asm.txt), [range-006b1eb0.asm.txt](recovered/request-callsites/range-006b1eb0.asm.txt).

Jalur `0xd025d8 -> 0x6b452c -> 0x6b4594` membaca key `token` melalui Flutter secure-storage lalu decode JSON. Refresh membandingkan masa berlaku, mengirim `refreshToken` dengan Authorization, dan menyimpan token hasilnya. Beberapa jalur legacy membaca key `access-token`. Audit ini tidak membaca token aktif dari perangkat dan belum membuktikan kontrak server logout/revocation.

Manifest base tidak memiliki inbound `ACTION_VIEW`/`BROWSABLE` redirect browser; HTTPS di `queries` hanya visibilitas intent. OAuth/OIDC/PKCE dan kesetaraan sesi browser/native belum terbukti. Endpoint relatif `login` yang ditemukan adalah konteks `SurveyMainRepository.loginTataUsaha`, bukan pengganti langsung `auth/signin`.

## Koordinat GNSS dan hasil ukur

`geotag/UploadGeotag` membuat enam key: `BerkasId`, `Lat`, `Longi`, `file`, `Lokasi`, `IsOffline`, lalu FormData. Satu jalur memformat dua double ke string melalui helper yang sangat cocok dengan `toStringAsFixed(7)` Dart 3.12.2; jalur lain meneruskan field model yang sudah ada. [Bukti forwarding dan batas inferensi](recovered/geotag-coordinate-dataflow.json). Ini belum membuktikan format semua cabang atau datum/CRS. Tidak ditemukan key mandiri accuracy, waktu fix, atau sumber/provenance GNSS pada map enam key ini. Waktu pada pembuatan nama `geotag_*.png` bukan bukti waktu pengukuran yang dikirim.

Survey memisahkan `koordinat_titik`, `koordinat_take_titik`, dan `jarak`. Titik objek hasil ukur tidak boleh disamakan dengan posisi pengambilan. Format, unit, datum/CRS, dan validasi jarak server belum diketahui. Field geolocator atau SQLite bukan bukti otomatis field outbound. Pertahankan metadata sumber, datum, waktu, dan akurasi pengukuran pada model lokal sampai mapping integrasi dapat divalidasi.

Logger memiliki latitude/longitude dalam bentuk request logging; itu tidak membuktikan geotag memiliki metadata akurasi/time yang sama. Isi dinamis `params`/`body` logger dan beberapa komponen survey bersarang belum dipulihkan seluruh leaf-nya.

## Reproduksi dan provenance

REA 4.1.0 digunakan untuk inventory XAPK/APK dan JavaScript asset. Blutter dibangun khusus Dart 3.12.2 dengan compiler lokal; perubahan tool meliputi penamaan output Windows untuk mencegah tabrakan case, flag compiler, dan pencatatan alamat initializer konfigurasi tanpa nilainya. Dump yang benar `blutter-unique/asm` memuat 2.276 library. APK dan `libapp.so` tetap sama dengan hash awal. Raw hasil disassembly tetap di `analysis`. [Verifikasi independen instruksi BL](http-callsite-verification.json) mengonfirmasi denominator 169 callsite yang sama.

Jalankan dengan interpreter lokal `tools/runtime/blutter-python/Scripts/python.exe`: `analysis/rea/build_request_contracts.py`, kemudian `analysis/rea/render_request_contracts.py`. Fragment review tersimpan terpisah dan generator memeriksa linkage call/method serta keberadaan bukti. Launcher REA: `tools/runtime/rea.cmd`; pemulihan Dart: `tools/blutter/run-recovery.cmd`.

Ini hasil pemulihan statis dari kode obfuscated. Tidak tersedia source asli, pembuktian parity seluruh fungsi, maupun hasil end-to-end terhadap server.
