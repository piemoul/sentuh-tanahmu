# Daring: formulir dan validasi awal identitas

Formulir Daring lima kolom dan adapter tindakan awal sudah diterapkan pada Docker lokal dan `https://sentuh.davay.space`. Ini kemajuan parsial menuju kesetaraan APK6.1.5, bukan penyelesaian seluruh menu atau verifikasi identitas dari awal sampai akhir. Pengguna mengonfirmasi APK pada Oppo juga6.1.5; kesamaan versi tidak menutup persoalan sumber peta langsung pada detail Berkas.

Formulir menampilkan Nama Lengkap, NIK Sesuai KTP, Tempat Lahir, Tanggal Lahir dan No.HP yang terhubung WhatsApp. Validasi edit dan pemeriksaan Lanjut dipisah mengikuti bukti native. Pemeriksaan akhir memakai empat teks controller yang ditrim sementara; tanggal berasal dari model. Nilai asli tidak ditimpa. Aturan trim mencakup U+0085. Tidak mengambil identitas pengganti dari profil login.

Lanjut yang lolos membuka pemeriksaan lima nilai. Tombol Kirim untuk validasi merupakan tindakan pengguna terpisah yang mengirim snapshot String tetap ke POST multipart `PeruriLivenessSdk/ValidateKTPDataV2`, berurutan `Nik`, `Nama`, `Tempatlahir`, `TglLahir`, `NoHp`, menggunakan sesi biasa dan konfirmasi wajib. Operasi ini adalah perubahan keadaan, bukan pembacaan. Tepat satu dari176 operasi diaktifkan; kini77 aktif. Korpus170 kontrak awal tidak berubah.

Respons HTTP200 harus mengikuti model native: nullable bool `error`, nullable String `message`, dan `data` JSON null/tidak ada. Data JSON nonnull gagal cast native dan ditolak adapter. Error null berarti true; pesan null memakai permintaan maaf native; pesan kosong dipertahankan. Status2xx selain200 menghasilkan tuple error status asli. Error true menuju Info; false hanya menuju batas OTP. Webapp menampilkan batas itu dan tidak mengirim OTP, membuka kamera, atau menyatakan akun selesai terverifikasi. Penanganan auth/jaringan browser yang sudah ada tetap berlaku. Tidak ada retry otomatis untuk penulisan identitas.

Adaptasi browser meliputi layar pemeriksaan sebelum kirim dan input tanggal kalender ISO yang dikonversi ke `dd/MM/yyyy`, dari1900 sampai hari lokal saat ini. Tanggal native awal2008-08-01 bukan batas umur18. Browser meminta pilihan tanggal eksplisit. Method formatter tSb/Cra/Dra belum terikat dengan bukti yang cukup; constructor/config saja tidak dipakai untuk menebak perubahan huruf, filter digit, pemotongan panjang, atau perilaku IME/grapheme. Pola birthplace yang dipulihkan dipakai, dengan kesetaraan seluruh edge RegExp tetap terbatas.

Sumber audit: [form](recovered/verification-daring-form-followup/flow.json), [input](recovered/daring-input-followup/flow.json), dan [respons](recovered/daring-identity-response-followup/flow.json). Verifier membandingkan instruksi dengan ELF yang dibekukan, serta pool dan metadata terkait. Fixture publik input memungkinkan tes tanpa APK atau direktori audit.

Hasil akhir:1129 tes Node lulus,1190 pemeriksaan VM pada23 suite lulus,19 pemeriksaan browser desktop1280×720 lulus. Review terpisah menemukan nol masalah material yang masih terbuka setelah koreksi trim. Tiga pengiriman identitas browser memakai data dan transport sintetis, tidak terhubung BPN. Seluruh permintaan produksi identitas/OTP/kamera dalam pengujian berjumlah nol. Respons terlambat setelah navigasi/sesi/reader berganti diabaikan; pengiriman ganda diblokir; teks server dan nilai pemeriksaan di-escape; log aktivitas tidak mencatat lima nilai identitas.

Container sehat;26 berkas frontend dan24 backend cocok dengan sumber. Image tanpa bind mount dan jaringan cocok pada50 berkas; HTTPS publik cocok pada26 frontend. Restart backend mengakhiri sesi memori. Login ulang dan refresh preview diperlukan. Belum ada uji penerimaan identitas asli, OTP/liveness, verifikasi akhir atau penerimaan layar Daring pada viewport mobile. Upload geotag tetap nonaktif; tidak ada pemalsuan kehadiran fisik atau attestation.

Ringkasan terikat hash: [daring-form-summary.json](webapp/daring-form-summary.json). Baseline53 runtime,22 ledger native dan334 receipt historis dipertahankan. Kegagalan awal tes yang disebabkan dependensi harness terisolasi disimpan; hasil koreksi memakai nama baru, tanpa menulis ulang bukti historis. Kode tahap ini belum diklaim sebagai checkpoint GitHub baru.
