# Validasi pembacaan Antrian Daring

Implementasi daftar dan detail Antrian akun sendiri **sudah diterapkan** di [Cloudflare](https://sentuh.davay.space/#/queue) serta [localhost](http://localhost:4173/#/queue). **Penerimaan API Antrian produksi belum diverifikasi.** [Agregat regresi](webapp/queue-list-regressions-2026-10-19.json), 19 Oktober 2026 08:36:35 UTC, mengikat `app.js` SHA-256 `bd52dd13091b5e0125117d2010d2eadd89462689540ecbe30797e2e48eacd46e` dan stylesheet `193d85d717fb259dc572003a3415f28aabd191378a94491404982b0df9b13b11`. Angka pemeriksaan bukan jumlah fitur selesai atau bukti kesetaraan seluruh APK.

## Implementasi dan batas akses

Registry memuat **171 operasi / 69 adapter aktif**, termasuk dua pembacaan Antrian. Daftar memakai `GET api/antrian/saya`; detail memakai `GET api/antrian/<ID utuh>`. Keduanya melalui klien Directus terpisah pada origin tetap `https://aplikasi.atrbpn.go.id`, tanpa body GET. Browser tidak dapat memasok NIK, profil, daftar identitas, bearer, URL layanan atau header upstream.

[Pengikat sesi](../webapp/private/queue-session.mjs) memperoleh profil dari `account/account_summary` milik sesi backend yang sama, melalui [parser profil](QUEUE-PROFILE-CONTRACT.md). Tidak ada fallback ke NIK sign-in. Subset web memakai identitas profil level 2/3 dengan `isIkd === false` dan daftar identitas tersimpan kosong; kondisi native yang menghasilkan daftar/join kosong berhenti sebelum GET. `isIkd` null pada cabang eligible ditolak. Ini bukan implementasi seluruh pengelolaan `user_antrian` native atau larangan universal bagi level/IKD lain; lihat [audit lifecycle identitas](QUEUE-IDENTITY-FOLLOWUP.md) dan [ledger beku](recovered/queue-identity-followup/flow.json).

Detail menerima hanya ID penuh yang telah dikembalikan daftar atau Aktivitas akun pada sesi yang sama. Routing Aktivitas mempertahankan prioritas Bidang/Berkas sebelum Antrian dan tidak memotong ID pada titik dua. ID detail dibatasi 1.024 karakter; separator URL, percent encoding dan karakter kontrol yang belum mempunyai bukti parity ditolak. Booking, Panggilan, editor identitas, verifikasi OTP, penambahan/penghapusan identitas dan mutasi antrean belum tersedia.

[Klien antrean](../webapp/private/queue-client.mjs) memakai bearer bundle secara privat dan baru menurunkannya ketika GET antrean nyata disiapkan. Token akun main tidak dipakai sebagai bearer antrean; queue 401 tidak menghapus login main. Profil TLS antrean hanya diberikan kepada origin tetap tersebut; cakupan TLS default main tetap terpisah. Verifikasi sertifikat tetap aktif, redirect ditolak, dan tidak ada material kredensial pada browser/laporan. Native menambahkan CA APK setelah builtin roots; penggunaan root Node bukan klaim bahwa root store sama dengan Android. Bukti: [transport](QUEUE-TRANSPORT-FLOW.md), [interceptor](QUEUE-INTERCEPTOR-FOLLOWUP.md), [query encoding](QUEUE-READ-FOLLOWUP.md), dan [root TLS](QUEUE-TLS-ROOT-FOLLOWUP.md).

## Tampilan dan adaptasi web

Daftar mempertahankan urutan serta field native nomor, tanggal, loket, lokasi, pemohon dan estimasi. Detail memakai ID item asli dan menampilkan nomor, kantor, lokasi kerja, loket group, tanggal kunjungan dan kode booking dalam urutan native. Detail dari Aktivitas memakai tampilan yang sama dan dapat kembali ke konteks daftar Aktivitas. Token pemohon divalidasi lalu dibuang; data pemohon bersarang tidak ditampilkan pada detail. [Audit UI](QUEUE-FLOW.md) dan [model/scalar](QUEUE-MODEL-FOLLOWUP.md) menjadi acuan.

Parser JSON antrean mempertahankan angka int64 kode booking sebagai teks, termasuk `9007199254740993`, tanpa pembulatan Number. Konversi scalar dan jumlah berkas mempunyai batas eksplisit pada audit model. Tanggal memakai `parseOfficeCalendarDate`, yaitu parser ISO web yang terbatas; kesetaraan seluruh parsing tanggal/timezone native belum dibuktikan. Dua kolom desktop menjadi satu kolom pada layar sempit. Gate login, tombol tidak tersedia, pesan gagal/kosong dan retry merupakan adaptasi browser. Refresh daftar menghapus data lama ketika gagal, sesuai pengujian alur ini.

Transport menerima 2xx dengan envelope/model yang sesuai; error bisnis tidak memicu retry. Status transient yang diaudit dapat mengulang maksimal tiga kali dengan jeda 1/3/5 detik. Pemetaan exception jaringan Node dibatasi secara eksplisit. Penolakan redirect, batas respons 20 MiB, UTF-8 fatal, pembatasan ID dan pembatalan sesi merupakan batas web; seluruh codec/exception native tidak diklaim identik.

## Bukti pengujian yang sudah tersedia

- [Tes backend Node](webapp/queue-backend-tests.txt): **239 lulus, nol gagal**, termasuk **14 tes integrasi sesi HTTP lokal** pada [queue-session.test.mjs](../webapp/tests/queue-session.test.mjs). Angka 14 merupakan subset 239. Transport upstream memakai fixture sintetis.
- [Agregat 19 suite fungsi aktual](webapp/queue-list-regressions-2026-10-19.json): **876 pemeriksaan lulus**, tanpa suite gagal atau perubahan input/historis selama run. Termasuk [72 pemeriksaan Antrian](webapp/queue-flow-latest.json), **36 panggilan API sintetis**, nol jaringan produksi. VM menguji parser/tampilan, ID utuh, Aktivitas, autoload, error/retry, ownership, navigasi dan perubahan sesi; ini bukan browser atau APK runtime.
- Review menemukan dua race yang telah dikoreksi: `summarySequence` mencegah internal summary lama menimpa observasi profil terbaru, dan detail memeriksa ulang otorisasi ID setelah response tiba. Signal autentikasi sesi membatalkan GET/retry saat logout, main 401, expiry/eviction atau shutdown; clear autentikasi hanya berlaku pada generasi token yang cocok. Tiga tes integrasi baru membuktikan summary lama, pencabutan ID saat detail pending, dan main 401 selama retry. Re-review source tidak menemukan regresi tambahan pada koreksi tersebut; tes tidak diulang oleh reviewer.

## QA browser dan deployment; produksi masih pending

Ini mencakup gate/login sintetis, dua baris, label detail, kode booking lebar, token tidak tampil, tidak ada overflow dokumen, kembali ke daftar, refresh error bisnis yang mengosongkan daftar, retry kosong, Panggilan belum tersedia, serta Aktivitas → detail bersama. Tidak ada error console yang teramati. Fixture dihentikan dan tab ditutup; viewport dipulihkan.

Belum ada GET API Antrian produksi yang dibuktikan.
