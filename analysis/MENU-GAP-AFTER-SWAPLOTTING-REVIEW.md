# Tindak lanjut setelah ringkasan draf Swaplotting

Sumber aktif21Oktober2026 mempunyai103 runtime,176 operasi/86 aktif (72 baca/14 tulis). Rilis Mitra sudah memperbaiki lima adapter baca dan mengujinya pada server asli. Rilis ringkasan Swaplotting menambah review lokal kedua formulir, tanpa mengubah backend/katalog atau mengaktifkan unggahan. Jangan mengulang dua gap tersebut sebagai belum dibangun.

**Langkah fungsional berikutnya: implementasikan pembacaan dan presentasi questionnaire Rating PPAT dari Aktaku.** [Service/model](RATING-PPAT-READ-FOLLOWUP.md) dan [UI/callback](RATING-PPAT-UI-FOLLOWUP.md) kini mempunyai proof ELF positif dan verifikasi independen, sehingga gap lama “bootstrap/model belum tertutup” tidak lagi menjadi alasan berhenti.

GET `RatingPPAT/GetRatingQuestions` memakai main FRb+7, tanpa query/body. HTTP200, shared transform, opsional satu decode JSON String service, kemudian root.data List. Envelope.error/message tidak dipakai. Grup Gyb mempertahankan `id,indikator` String nullable dan nested `jawabanRatingPPAT` List nullable; `kategori` String nullable divalidasi lalu dibuang. Opsi Hyb mempertahankan `id,pertanyaan,jawaban` String nullable; `bobot,nilai` String nullable divalidasi lalu dibuang. Jangan membuat field angka/bintang, fallback root-array/message, ID atau jawaban pengganti.

Entry Aktaku membawa selected `aktaId??''` dan `namaPPAT??''`. Judul `Rating PPAT `+nama. Init otomatis membaca pertanyaan. Pertahankan urutan/duplikasi/null; grup berjudul nomor urut+indikator, deskripsi dari pertanyaan opsi pertama, semua opsi radio memakai jawaban String. Map native groupID→answerID mengabaikan perubahan null atau groupID null. Duplicate IDs berbagi key; validasi native membandingkan ukuran map dengan jumlah grup. Guard browser untuk null/duplikasi harus dinyatakan sebagai adaptasi, bukan mengarang referensi yang valid.

Scope implementasi berikutnya boleh menambah decoder GET bertipe, lifecycle baca, renderer dan pilihan lokal, dengan tests serta fixture browser untuk dua entrycase dan error/retirement. **POST jawaban tetap terpisah dan nonaktif** sampai service writer, auth, validation/reconciliation dan response semantics terbukti. Dialog native hanya menampilkan message tuple tanpa memeriksa bool; itu tidak membuktikan keberhasilan bisnis server.

Gap lain tetap: tujuan Perjalanan Berkas RAb lengkap; final booking; uji populated/error/role seluruh menu; penerimaan transaksi; runtime APK asli; uji perangkat/GNSS; tile sertipikat yang belum dikorelasikan; binding peta langsung Berkas belum tertutup. Personal Swaplotting kini dapat meninjau nilai/byte-handle lokal, tetapi serialisasi multipart lengkap/filename generator/MIME runtime/HTTP belum ditutup. Geotag yang mensyaratkan kunjungan tidak dibypass dengan koordinat hasil ukur.

Preview publik Swaplotting saat rilis menampilkan login gate yang benar. Belum ada uji draf dengan data akun asli pada fitur ringkasan. Pembaruan frontend memakai bind-mount sehingga container/backend tidak direstart. Pertahankan sesi yang ada dan tunda kebutuhan login berikutnya sampai implementasi backend Rating siap agar tidak meminta login berulang untuk setiap perubahan kecil.
