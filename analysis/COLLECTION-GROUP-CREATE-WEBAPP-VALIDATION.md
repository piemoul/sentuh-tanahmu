# Validasi webapp Buat Grup Bidang

Formulir khusus mengikuti [kontrak APK](COLLECTION-GROUP-CREATE.md) dan [ledger statis](recovered/collection-group-create/flow.json). Pembukaan baru selalu kosong; submit memangkas whitespace native, termasuk U+0085, lalu mengabaikan nama kosong. Tombol Batal/submit dinonaktifkan selama menyimpan, sedangkan input tetap bisa diedit. Request hanya membawa field multipart GroupName ke Collection/AddPersilCollectionGroup. Konfirmasi backend yang sudah ada tetap diwajibkan.

Respons HTTP200 diperiksa sebagai envelope nullable bool/String/String tanpa coercion atau decode JSON kedua. Nilai error:true pada model valid mengikuti hasil sukses native. Setelah sukses, hanya grup dimuat ulang; tidak ada insert optimistis atau refresh baris Koleksi. Sheet menutup setelah refresh selesai, termasuk kegagalan refresh biasa. Guard sesi, halaman dan kepemilikan modal mencegah hasil terlambat mengubah tampilan pengganti.

[Rekap bukti](webapp/collection-group-create-verification-summary.json) mengikat 389 tes Node, 1035 pemeriksaan fungsi dalam 21 suite dan 21 pemeriksaan browser lokal. Semua uji memakai transport sintetis; **tidak ada grup akun asli yang dibuat**. Secara terpisah, lima pemeriksaan baca akun asli sebelum rebuild adapter create berhasil: Berkas kosong, satu Bidang/nol grup, peta dengan pin terpusat pada zoom20 dan kedua raster, pembukaan form kosong serta batal. Tidak ada create produksi. [Bukti baca akun](webapp/collection-group-create-live-read-before-rebuild.json) mengikat frontend saat ini dengan backend baca rilis sebelumnya; ini bukan penerimaan create produksi. Peta OSM/Bhumi tidak berubah.

Deployment Docker dan empat aset publik sesuai hash sumber. Preview setelah rebuild masih anonim sehingga penerimaan create server asli belum terbukti. Batas validasi katalog lama (16000 karakter/NUL dan coercion angka pada form generik) merupakan adaptasi browser; pesan non200 disanitasi. Kesetaraan piksel/Flutter, mutasi lain, peta langsung BERKAS, keseluruhan aplikasi dan submisi geotag masih belum selesai.
