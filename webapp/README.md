## Menjalankan

Dari workspace utama, buka `START-WEBAPP.cmd`, atau:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-webapp-docker.ps1
```

Buka **http://localhost:4173**. Deployment utama memakai Docker Desktop dan hanya memublikasikan port pada loopback komputer ini. `-NoBrowser` menjalankan container tanpa membuka tab. File frontend publik pada compose dipasang hanya-baca dari workspace; perubahan tampilan cukup dimuat ulang di browser tanpa mengakhiri sesi backend. Perubahan backend memerlukan `-Rebuild` dan mengakhiri sesi lama. Hentikan dengan `docker compose stop webapp`. Lihat `DOCKER.md` di workspace utama untuk konfigurasi HTTPS domain Cloudflare Tunnel pada tahap berikutnya.

Snapshot historis sumber `1c4834de…a528ff` menambahkan Cari Berkas dengan pemilih kantor, CAPTCHA manual dan pembacaan utama → SOP → status cetak sesuai audit native. Sebanyak 118 tes Node dan 574 pemeriksaan dalam 13 rangkaian fungsi frontend lulus. Dua puluh pemeriksaan browser memverifikasi formulir/pemilih kantor tanpa menyelesaikan CAPTCHA; pencarian berhasil ke server asli belum diuji. Bukti browser/live Mitra (`8e2eeb01…042be2`) dan bootstrap/profil (`607b2cd7…29c86c`) tetap historis. Detail bukti dan batas kesetaraan ada di [status kesetaraan](../analysis/WEBAPP-PARITY-STATUS.md).

Mitra Kerja kini memakai lima tampilan baca yang diaudit dalam tiga kategori berurutan: **PPAT**, **Surveyor**, **Penilai**. Pemilihan kantor/provinsi membuka daftar anak dengan ID baris terpilih utuh melalui adapter yang sudah aktif. Respons memakai HTTP 200 dan daftar body.data dengan field string nullable. Runtime Node khusus untuk pengujian/native ada di `tools/runtime/node.exe`. Tidak perlu npm install atau build frontend. Alternatif menjalankan native dari folder workspace saat container dihentikan:

```powershell
.\tools\runtime\node.exe --openssl-legacy-provider .\webapp\server.mjs
```

Konfigurasi adapter login dan identitas TLS klien dibaca di memori dari artefak lokal yang hash-nya diverifikasi. Opsi runtime diperlukan untuk membaca kemasan PKCS12 lama dalam APK; koneksi tetap menggunakan TLS modern. Menyalin folder `webapp/` saja tidak membawa konfigurasi tersebut. Konfigurasi tersedia tidak membuktikan penerimaan akun oleh server.

## Menguji melalui webapp

1. Buka **Pengujian Lanjutan** dan jalankan pemeriksaan lokal untuk memeriksa server, katalog, serta konfigurasi.
2. Masuk melalui **Profil** dengan akun pengguna sendiri. Password dikirim melalui server lokal ke endpoint HTTPS `auth/signin` pada `sentuh.atrbpn.go.id`. Profil akun dimuat setelah login untuk menentukan menu yang sesuai. Browser tidak menyimpan token akses/refresh. Token sesi berada di memori server dengan cookie lokal HttpOnly dan SameSite.
3. Buka **Beranda** lalu **Sertipikatku**, **Berkasku**, **Aktaku**, atau menu layanan lain. Tekan Tampilkan data untuk membaca data. Info Layanan dimuat otomatis tanpa login, menyediakan pencarian lokal, detail halaman penuh dan simulasi biaya sesuai jenis layanan. Tab Tanah, Wakaf dan Hak Tanggungan pada Sertipikatku, Berkasku, dan Koleksi menyediakan alur daftar ke detail dengan ID yang dibuktikan dari APK. Detail Tanah/Wakaf memilih endpoint analog atau elektronik sesuai StatusEl; Hak Tanggungan membuka Daftar Sertipikat terkait. Tidak ada data akun contoh yang diperlakukan sebagai data server.
4. Periksa status HTTP, hasil, dan pesan kesalahan. Penerimaan server hanya dapat dibuktikan oleh respons aktual. Penolakan versi, izin, atau integritas tetap ditampilkan sebagai kegagalan.
5. Untuk operasi yang mengubah data, periksa tujuan, field, file, dan koordinat pada langkah review sebelum tombol pengiriman akhir.

**Cari Berkas** kini memakai pemilih Kantor Pertanahan, nomor berkas, pilihan tahun sebelumnya/tahun berjalan, dan CAPTCHA enam digit yang diisi manual. Daftar kantor berasal dari respons list langsung `legacy/Kantah` dengan `nama` kosong serta `tipeKantor=3,2,1`; pencarian nama berlangsung lokal dan preferensi kantor profil tidak memilih kantor otomatis. ID kantor tetap berasal dari baris terpilih, tanpa input ID teknis. Refresh CAPTCHA hanya mengganti tantangan serta mempertahankan jawaban dan error; validasi belum lengkap mempertahankan tantangan dan jawaban, sedangkan sukses/tidak ditemukan mengganti tantangan dan mengosongkan jawaban.

Pencarian membaca respons utama, lalu SOP dan status cetak secara berurutan memakai berkasId dari respons utama. SOP gagal menghentikan alur tanpa menampilkan detail; kegagalan status cetak biasa memakai tanda `-` dan tetap membuka detail. Detail menggantikan formulir, tanpa membaca ulang respons utama atau meminta SPS; Kembali memulihkan kantor/nomor/tahun, dan hasil tambahan disimpan agar render ulang tidak mengulang request. Kepemilikan state/request mencegah respons lama dari halaman atau sesi yang ditinggalkan mengaktifkan hasil kembali. Audit dan regresi: [Cari Berkas](../analysis/SEARCHFILE-FLOW.md), [fungsi aktual](../analysis/webapp/searchfile-flow-latest.json), serta [baseline sebelum perbaikan](../analysis/webapp/searchfile-flow-before-fix.json). Pencarian berhasil ke server asli belum diklaim.

[Tambahan bukti form nullable](../analysis/recovered/searchfile-null-form/null-form.json) menetapkan `berkasId:null` sebagai key form tanpa tanda `=`, berbeda dari string kosong atau key yang tidak ada. [Bukti transport lanjutan](../analysis/recovered/searchfile-null-form/transport-followup.json) menetapkan encoding komponen UTF-8, spasi `+`, `*` ter-encode dan `~` tetap. Adapter membatasi penyesuaian ini pada CariBerkas, mengizinkan `nama` kosong untuk pencarian kantor native, serta mempertahankan semantik body.error CariBerkas pada HTTP 200 dan status cetak pada respons 2xx yang berhasil. Status HTTP dan pemeriksaan sesi tetap berlaku. ID kosong ditolak secara sengaja; pencarian null-safe, hubungan initializer formatter angka yang belum lengkap, batas panjang widget/backend dan kesetaraan tampilan/Unicode tetap dicatat sebagai batas.

Pembaca bagian tambahan BERKAS juga memeriksa urutan detail, keterhubungan slot dan dialog terbuka sebelum menangani error autentikasi. Respons kedaluwarsa dari detail yang sudah diganti, slot yang terlepas atau dialog yang ditutup tidak lagi menghapus sesi/data yang sedang digunakan.

Setelah reload dengan sesi aktif, webapp kini memuat ringkasan akun setelah status sesi dan katalog berhasil dibaca, sehingga menu Aktivitas/Koleksi kembali tampil sesuai syarat profil native. Startup tanpa sesi tidak membaca profil. Kegagalan profil biasa mempertahankan login, menyembunyikan menu yang membutuhkan kelayakan profil dan menyediakan percobaan ulang; kedaluwarsa autentikasi membersihkan sesi. Pembacaan profil otomatis, formulir profil dan katalog berbagi penjagaan pemilik hasil sehingga respons lama tidak mengganti profil baru atau sesi pengganti. Logout segera menghapus data pribadi lokal; login, reload dan pemuatan profil ditahan selama logout masih menunggu, termasuk penyelesaian login lama yang sebelumnya dapat mengaktifkan tombol terlalu dini.

Katalog berisi 176 bentuk request: 170 entri awal dari 169 callsite, ditambah viewer SPS, dua DELETE grup/membership dan tiga operasi item koleksi yang diaudit terpisah. Sebanyak 75 adapter operasi tersedia untuk pengujian, ditambah alur login khusus. Kontrak lain tetap belum aktif atau untuk inspeksi; unggah geotag membutuhkan aplikasi resmi. Jumlah ini bukan jumlah fitur lengkap aplikasi. Katalog berada di Pengujian Lanjutan. Peta sumber menu dan batas bukti ada di `analysis/official-menu-map.json`.

Detail analog menampilkan ringkasan, Lokasi Bidang Tanah, Pemilik, Surat Ukur, dan Catatan Pendaftaran menurut binding APK. Seluruh record tetap tersedia melalui kelompok yang dapat dibuka; catatan tidak disaring berdasarkan Status, dan tanggal mempertahankan teks server tanpa perubahan zona waktu. Koleksi PERSIL mengambil batas dari contentId utuh dan menampilkan sketsa yang dapat diperbesar/digeser; BERKAS memakai bagian pertama contentId sebelum `:` untuk mengambil respons utama berkas. `GetCollectionId` adalah pemeriksaan status koleksi berkas, bukan pengambil detail PERSIL.

Detail elektronik mempunyai renderer sendiri untuk ringkasan, Lokasi Bidang Tanah, Pemilik, dan Catatan Pendaftaran. Nomor, status cetak/blanko, baris opsional, serta item yang dibagikan mengikuti kondisi yang ditemukan pada APK. Pemilik berupa daftar string; tampilan catatan memakai kolom1, sedangkan seluruh empat kolom mentah tetap tersedia pada rincian terpisah. Kode Sertipikat disembunyikan pada ringkasan dan preview item yang dibagikan. Tanggal dan luas mempertahankan teks sumber dengan batas format yang tercatat pada audit; model tidak dikenal tetap ditampilkan melalui renderer umum. **Lihat Sertipikat** kini tersedia melalui alur dokumen elektronik berikut; QR dan berbagi akses tetap belum diaktifkan.

**Lihat Sertipikat** kini tersedia pada detail elektronik yang berhasil dimuat, termasuk item dibagikan. Referensi memakai SertifikatId dari baris daftar terpilih ditambah `:SERTIPIKATKU`, bukan ID/NIBel dari respons detail. Nama hanya berasal dari `nama` ringkasan akun sesi saat ini; cache profil valid dapat dipakai, nama null menjadi kosong, dan tidak ada fallback username/email/pemilik atau input manual. Tombol hanya mengikuti status pemuatan/busy sendiri, tanpa menyalin syarat QR/cetak/share. Setelah PDF tervalidasi, tersedia pratinjau, unduhan, muat ulang dan **Lihat lokasi** dengan q bersufiks yang sama melalui pembaca lokasi dokumen. Alur ini tidak meminta GetDocumentType atau scanDocument. ## Koordinat pengukuran

Masukkan koordinat secara manual atau impor CSV/GeoJSON/NMEA. Koordinat menggunakan WGS84 / EPSG:4326 dalam derajat desimal. Proyeksi lain harus ditransformasikan sebelum impor. Sumber, waktu, akurasi, dan nilai asli dipertahankan sebagai keterangan lokal. Pembacaan langsung perangkat GNSS melalui USB/Bluetooth belum tersedia.

Header CSV minimal:

```csv
latitude,longitude,name,source,accuracy_m,measured_at,crs
```

Sumber yang didukung: `survey`, `external_gnss`, `browser`. `accuracy_m` dan `measured_at` boleh kosong; aplikasi tidak menciptakan nilai pengganti. Waktu harus memuat zona, misalnya `2026-10-18T09:30:00+07:00`. GeoJSON harus berupa `FeatureCollection` dengan geometri `Point`, dalam urutan **[bujur, lintang]**. Maksimum 500 titik / 2 MB.

Parser NMEA membaca GGA/RMC dengan checksum valid dan mengecualikan fix yang ditandai invalid, estimated, manual, atau simulated. HDOP tidak dikonversi menjadi akurasi meter; GGA tanpa tanggal tidak diberi waktu rekaan. Implementasi mengacu pada [dokumentasi NMEA produsen Inertial Sense](https://docs.inertialsense.com/user-manual/com-protocol/nmea/). Perbedaan keluaran penerima perlu diverifikasi dengan perangkat yang dipakai.

Halaman Perbandingan Koordinat menghitung jarak sferis dan arah antara dua titik yang Anda masukkan. Label referensi berkas tidak berarti koordinat sudah diverifikasi terhadap BPN. Endpoint metadata lokasi bidang yang diaudit hanya mengembalikan ID/wilayah/hak/nomor, bukan koordinat.

Sketsa batas bidang berasal dari endpoint batas yang terpisah. Geometri dibaca dalam urutan [bujur, lintang], tanpa mengubah koordinat sumber. Sketsa tidak memiliki peta dasar dan tidak membuktikan datum, ketepatan hasil ukur, atau kehadiran di lokasi. Data geometri yang tidak didukung atau tidak valid ditolak dengan pesan yang jelas.

Audit membuktikan batas 10 m membandingkan titik penandaan terhadap posisi perangkat saat kunjungan, bukan sekadar akurasi GPS. Unggah `geotag/UploadGeotag` dinonaktifkan di backend termasuk jalur offline; koordinat berkas tidak dapat dipakai menggantikan posisi perangkat atau bukti kunjungan. Enam field aslinya tetap tersedia untuk inspeksi kontrak. Unduhan surat geotag yang sudah ada tidak membuat atau menandatangani pernyataan baru. Rincian di `analysis/GEOTAG-VALIDATION-AUDIT.md`.

Pengujian saat kunjungan fisik direncanakan untuk tahap berikutnya dan belum dilakukan. Unggah geotag masih dinonaktifkan pada build saat ini.
